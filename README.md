# 📚 NotesHub — Collaborative Student Notes Sharing Platform

A full-stack web application built with **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript** that allows students to upload, share, search, and download academic notes.

## 🌐 Live Demo
👉 [https://noteshub.wuaze.com/index.php](https://noteshub.wuaze.com/index.php)

## ✨ Features
- 🔐 User Registration & Login
- 📤 Upload & Download Notes
- 🔍 Search Notes
- 🔖 Bookmark Notes
- ⭐ Ratings & Reviews
- 🛡️ Secure Admin Panel for content & user management

## 🛠️ Tech Stack
| Frontend | Backend | Database |
|----------|---------|----------|
| HTML, CSS, JavaScript | PHP | MySQL |
